## 🔍 Проверка интеграции

### Шаг 1: Запуск сервисов

```bash
# Запуск через Docker
make up

# Или вручную
# Backend
cd backend && npm run start:dev

# Frontend
cd frontend && npm run dev
```

### Шаг 2: Проверка CORS

1. Откройте браузер DevTools (F12)
2. Перейдите на http://localhost:5173
3. Попробуйте залогиниться
4. Проверьте Network tab - не должно быть CORS ошибок

### Шаг 3: Проверка авторизации

1. Зарегистрируйте нового пользователя
2. Войдите в систему
3. Проверьте, что токен сохраняется в localStorage
4. Проверьте, что запросы содержат Authorization header

### Шаг 4: Проверка загрузки изображений

1. Перейдите на страницу товаров
2. Создайте новый товар
3. Загрузите изображение (любого размера и формата)
4. Проверьте, что изображение сжалось
5. Проверьте, что изображение отображается в списке

### Шаг 5: Проверка обработки ошибок

1. Попробуйте создать товар с невалидными данными
2. Проверьте, что показываются ошибки валидации
3. Попробуйте удалить товар - должно появиться подтверждение
4. Проверьте, что Toast уведомления работают

### Шаг 6: Проверка отчетов

1. Создайте несколько продаж
2. Перейдите на страницу отчетов
3. Проверьте, что графики отображаются
4. Попробуйте экспортировать данные в CSV

## 🐛 Известные проблемы и решения

### Проблема: CORS ошибки

**Решение:**
- Проверьте, что backend запущен на порту 3000
- Убедитесь, что frontend URL в allowedOrigins
- Проверьте, что credentials: true в CORS настройках

### Проблема: Изображения не загружаются

**Решение:**
- Проверьте, что папка `backend/uploads/products` существует
- Убедитесь, что у процесса есть права на запись
- Проверьте размер файла (максимум 5MB до сжатия)

### Проблема: Ошибки TypeScript

**Решение:**
- Запустите `npm run type-check` в frontend
- Убедитесь, что все типы импортированы правильно
- Проверьте `tsconfig.json` настройки
