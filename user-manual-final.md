# Руководство пользователя Warehouse Management System

## Введение

Добро пожаловать в систему управления складом (Warehouse Management System). Это приложение предназначено для автоматизации учета товаров, управления продажами и возвратами, а также для аналитики деятельности склада.

## Начало работы

### Вход в систему

Для доступа к системе необходимо авторизоваться. Используйте учетные данные, предоставленные администратором.

1. Откройте страницу входа.
2. Введите **Email** и **Пароль**.
3. Нажмите кнопку **"Войти"**.

> **Примечание:** Если вы забыли пароль, обратитесь к администратору системы для его сброса.

---

## Роли и Доступ

В системе предусмотрено три основные роли пользователей, каждая из которых имеет свой уровень доступа:

| Раздел / Функция | Продавец (Seller) | Менеджер (Manager) | Администратор (Admin) |
| :--- | :---: | :---: | :---: |
| **Панель управления (Dashboard)** | Ограниченный вид | Полный вид | Полный вид |
| **Продажи** | ✅ Создание, Просмотр | ✅ Полный доступ | ✅ Полный доступ |
| **Товары** | 👁️ Просмотр | ✅ Создание, Редактирование | ✅ Полный доступ |
| **Возвраты** | ❌ Нет доступа | ✅ Полный доступ | ✅ Полный доступ |
| **Отчеты** | ❌ Нет доступа | ✅ Просмотр, Экспорт | ✅ Просмотр, Экспорт |
| **Пользователи** | ❌ Нет доступа | ❌ Нет доступа | ✅ Управление |
| **Типы транзакций** | 👁️ Просмотр | ✅ Создание, Редактирование | ✅ Полный доступ |
| **Аудит (Логи)** | ❌ Нет доступа | ✅ Просмотр | ✅ Просмотр |
| **Настройки** | 👤 Личный профиль | 👤 Личный профиль | ⚙️ Системные настройки |

## Основные Разделы

### 1. Панель управления (Dashboard)

Главная страница отображает сводную информацию о состоянии склада. Вид зависит от вашей роли:

*   **Для всех ролей:**
    *   **Низкий запас:** Список товаров, количество которых меньше минимального порога.
    *   **Последние продажи:** Таблица с 5 последними операциями продаж.
    *   **Новые поступления:** Список недавно добавленных товаров.

*   **Только для Менеджеров и Администраторов:**
    *   **Общая статистика:** Карточка с показателями (Всего позиций, Активные товары, Продано, Возвращено, Общая стоимость).
    *   **Динамика продаж:** График продаж за последний период.
    *   **Последние возвраты:** Список последних операций возврата.

### 2. Управление Товарами

Раздел **"Товары"** позволяет работать с номенклатурой склада.

*   **Поиск и Фильтрация:** Используйте строку поиска и фильтры по категориям/складам для быстрого нахождения товара.
*   **Добавление товара (Менеджер/Админ):** Нажмите "Добавить товар", заполните обязательные поля (Название, Артикул, Цена, Количество) и сохраните.
*   **Редактирование (Менеджер/Админ):** Изменение характеристик товара.
*   **Удаление (Админ):** Полное удаление товара из системы.

### 3. Продажи

Раздел для оформления отгрузок товара.

> **Важно:** В текущей версии приложения интерфейс создания продаж находится в разработке. Функционал доступен только через API.

*   **История продаж:** Доступна для просмотра администраторам и менеджерам через раздел "Отчеты".

### 4. Возвраты (Менеджер/Админ)

Управление возвратами товаров от клиентов.

> **Важно:** В текущей версии приложения интерфейс оформления возвратов находится в разработке. Функционал доступен только через API.

*   **Влияние на склад:** Возвращенный товар автоматически возвращается на остатки склада.

### 5. Отчеты (Менеджер/Админ)

Раздел аналитики для принятия управленческих решений.

*   **Типы отчетов:**
    *   **Продажи:** Выручка, Прибыль, Количество чеков.
    *   **Остатки:** Текущая стоимость склада, оборачиваемость.
    *   **Возвраты:** Статистика по причинам и объемам возвратов.
*   **Фильтры:** Выбор периода (Дата начала - Дата окончания).
*   **Экспорт:** Возможность выгрузки отчетов в Excel/CSV.

### 6. Аудит и Безопасность (Менеджер/Админ)

Система ведет журнал всех критических действий (Audit Log).

*   **Просмотр логов:** Доступен в разделе настроек или аудита.
*   **Фильтрация:** По пользователю, действию (создание, удаление, вход в систему), дате.
*   **Назначение:** Позволяет отследить, кто и когда изменил данные товара или оформил продажу.

### 7. Управление пользователями (Админ)

Полный контроль над учетными записями сотрудников.

*   **Создание пользователя:** Указание Email, Имени, Роли и Пароля.
*   **Блокировка:** Временное ограничение доступа без удаления аккаунта.
*   **Сброс пароля:** Принудительная смена пароля пользователя.

### 8. Типы транзакций

Справочник типов операций (Приход, Расход, Списание и т.д.).

*   **Менеджеры** могут создавать и редактировать типы.
*   **Администраторы** имеют право удалять типы транзакций.

## Техническая поддержка

Если вы столкнулись с ошибкой "403 Forbidden" или "Insufficient permissions", убедитесь, что у вашей учетной записи достаточно прав для выполнения действия (см. таблицу Ролей).

При возникновении технических проблем (ошибки соединения, некорректное отображение данных) попробуйте:
1. Обновить страницу браузера.
2. Очистить кэш (Ctrl+F5).
3. Перезайти в систему.

Если проблема сохраняется, обратитесь к системному администратору.
