## Build/Test commands
- Любые команды, которые могут генерировать большой вывод и расходовать много токенов, запускать только по прямому запросу пользователя.
- Не запускать `npm run build`, `npm run lint`, `npm test`, `vitest`, `jest` и другие тяжелые проверки без явной просьбы пользователя.
- По умолчанию не выполнять сборку, линт и тесты после изменений.
- Если проверка действительно нужна, сначала спросить пользователя.
